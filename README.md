# 대전대학교 전공탐색 박람회 홈페이지 시안

승인된 13차 시안입니다. `index.html`을 브라우저에서 직접 열면 됩니다. 이미지와 CSS·JavaScript가 내장되어 별도 설치가 필요하지 않습니다.

## 화면
- 행사 안내(홈): 메인 배너, 대표 프로그램, 부스 배치도
- 참여 학과: 구성 확인용 카드와 E-Book 안내
- 일정표: 전야제·본행사 전환
- 참가 신청: 신청 안내 영역

## 상태
운영안 반영 시안이며 세부 내용은 변경될 수 있습니다. 미확정 전야제 시간·장소, 학과 목록, 이미지, 문의번호는 준비 중으로 표시합니다.
E-Book·학과별 소개·사전등록 주소는 아직 연결되지 않았으며 실제 신청을 받지 않습니다. 링크는 HTML의 `CONFIG`에서 설정할 수 있습니다.

## 검증 및 배포
PC·모바일 화면, 고정 메뉴, 일정 전환 및 미등록 링크 안내 동작을 확인했습니다.
별도 승인에 따라 전용 Nginx 컨테이너로 수동 배포합니다. GitHub Pages 및 자동 배포 설정은 없습니다.

## 자료 관리
학교 로고·캐릭터는 대전대학교 공식 홈페이지 공개 자료를 시안에 사용했습니다. 재사용 권한은 각 권리자에게 있습니다.
PEM·인증정보·내부 기획 문서·생성 로그·이전 시안은 저장소에서 제외합니다.
